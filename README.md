# 🚀 PrepPilot – AI-Powered Personalized Learning Assistant

PrepPilot is a personalized learning assistant designed to help students study smarter through structured study plans, quizzes, and answer evaluation.

## ✨ Features

### 📚 Personalized Study Planner
- Generate structured study schedules.
- Organize topics into daily learning tasks.
- Set study duration and daily study hours.

### 🧠 AI Quiz Generator
- Generate quizzes based on subject and topic.
- Select difficulty levels.
- Practice concepts through interactive learning.

### 📝 Answer Evaluator
- Submit answers for evaluation.
- Receive feedback and improvement suggestions.
- View answer word count.

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- AI integration: BharatCode API (integration in progress)
- Development tools: VS Code, Git, GitHub

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/abhishekwakade/PrepPilot.git
```

2. Open the project folder:

```bash
cd PrepPilot
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file in the root directory:

```env
AI_MODE=demo
BHARATCODE_API_KEY=your_api_key_here
```

5. Start the server:

```bash
node server.js
```

6. Open your browser:

```text
http://localhost:5000
```

## 🔐 Environment Variables

Never commit your `.env` file or expose your API key.
